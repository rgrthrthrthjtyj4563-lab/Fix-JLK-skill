# report_content.md 草稿模板

AI 生成 `report_content.md` 时必须严格按此模板结构填充。
程序只负责维度骨架、校验、渲染和 Word 模板继承；正文必须全部由 AI 提供。

---

## 标题层级硬契约

| 章节 | 必需层级 | 禁止层级 | 备注 |
|------|----------|----------|------|
| 顶层报告章节 | `##` | `#`、`###` 及以下 | 一级标题被 preflight 直接拒绝 |
| `4.x` 维度章节 | `###` | `####` | 必须形如 `### 4.1 维度名称` |
| 单题小标题 | `####` | `### 4.1.1 ...` | 被识别为新 4.x 章节 |
| `5.x` 子章节 | `###` | `##`、`####` | 三级标题直接跟正文 |

- `#` 一级标题：preflight 输出 `use ## for a top-level report section` 并拒绝。
- `### 4.1.1 ...`：preflight 输出 `use #### for a subtopic` 并拒绝。
- 标题标记后必须有空格（`#### 用药行为分析`，不是 `####用药行为分析`）。
- 小标题只写语义名称；不要附加 `4.1.1`、破折号或 `q01`。最终 Word 的 `（1）` 顺序号由渲染器统一添加。

## 内容质量规则

所有检查都在 `preflight_report_content()` 中一次性执行，`build_payload` 不再产生新的内容质量错误。

### 4.x 单题正文

| 检查项 | 要求 | 失败消息示例 |
|--------|------|-------------|
| 段数 | 恰好 1 段 | `4.1 / q01 / 血压控制效果分析：实际 2 段；需要恰好 1 段；请将多段合并。` |
| 字数 | 250-300 字 | `4.1 / q01 / 血压控制效果分析：正文 238 字，要求 250-300 字，还需补充至少 12 字。` |
| 百分比 | 必须含数字百分比 | `4.1 / q01 / ...：缺少数字百分比（如 39.13%）；请标注关键数据百分比。` |
| 判断词 | 说明/表明/反映/提示 | `4.1 / q01 / ...：缺少分析判断词；请在正文中加入分析判断。` |
| 收束词 | 整体看/后续/需/仍 | `4.1 / q01 / ...：缺少收束词；请在正文结尾加入收束语句。` |
| 禁用模式 | 无 A/B/C/D 等 | `4.1 / q01 / ...：包含禁用模式；请改用选项语义表述。` |
| 句子长度 | 单句 ≤110 字 | `4.1 / q01 / ...：存在超长单句；请拆分为结论、解释和收束句。` |
| 段尾质量 | 无重复句、连续标点或通用套话 | `4.1 / q01 / ...：段内存在重复句；请删除语义雷同的结尾。` |

### 5.x 正文

| 检查项 | 要求 | 失败消息示例 |
|--------|------|-------------|
| 5.1 段数 | 2 段 | `5.1问卷重点问题分析：实际 3 段；需要恰好 2 段。` |
| 5.1 字数 | 每段 250-350 字 | `5.1问卷重点问题分析 / 第 1 段：正文 220 字，要求 250-350 字。` |
| 5.1 判断词 | 说明/表明/反映/提示/判断 | `5.1问卷重点问题分析 / 第 1 段：缺少 analytical judgment。` |
| 5.2 段数 | 3-5 段 | `5.2调研结果总结：实际 2 段；需要 3-5 段。` |
| 5.2 字数 | ≤ 700 字 | `5.2调研结果总结：总字数 750 字，不超过 700 字。` |
| 5.2 品种/地区 | 必须提及 | `5.2调研结果总结：未提及产品或地区。` |
| 5.3 建议条数 | 2-4 条 | `5.3建议：实际 1 条；需要 2-4 条。` |
| 5.3 载体 | 提醒卡/药盒/等 | `5.3建议：缺少 concrete tools or carriers。` |

`5.1`、`5.2`、`5.3` 也执行单句 ≤110 字、无连续标点、无段内重复句和无通用收尾套话的检查。

## 两阶段模式

- **一键模式**：`python3 scripts/run_report_pipeline.py questionnaire.xlsx report_content.md --output-docx report.docx`
- **两阶段模式**：
  1. AI 生成 `report_content.md` 并保存到 `tmp/runs/{timestamp}-{slug}/report_content.md`
  2. 运行 `python3 scripts/run_report_pipeline.py questionnaire.xlsx report_content.md --output-docx report.docx`
  - 如果 preflight 失败，输出 `PREFLIGHT_FAILED` 及具体错误列表，保留 `preflight.json` 诊断文件
  - AI 基于错误列表直接修复对应位置，无需重写整份报告
